## Issues Encountered and Solutions

### Issue 1: Git was not installed

**Problem:** Git was not recognized in Cursor initially.

**Solution:** Git was installed using winget, and Cursor was restarted so the PATH updates could apply correctly.

### Issue 2: Finding the Clone Repository option

**Problem:** I could not initially find the "Clone Repository" option inside Cursor.

**Solution:** I used the Command Palette (`Ctrl + Shift + P`) and selected "Git: Clone" to clone the repository successfully.
